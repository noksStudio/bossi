# Bossi

מערכת הפעלה לעסק — לניהול הלקוחות, הכסף והמסמכים במקום אחד.

**כל מה שאתה יודע על הלקוחות שלך — במקום אחד.**

הידע על הלקוח קיים בעסק. הוא פשוט מפוזר בין וואטסאפ, מייל, דרייב, ואצבע אחת בראש
של מישהו. Bossi אוספת את המסמכים, אנשי הקשר וההיסטוריה של כל לקוח לציר זמן אחד,
ונותנת שלושה דברים:

| | |
|---|---|
| **ריכוז** | הכול נכנס לבד — מייל ייעודי, וואטסאפ, סריקה — ונוחת על הלקוח הנכון |
| **שליפה** | שאלה בעברית, תשובה עם ציטוט מעמוד וסעיף |
| **סדר** | דשבורד שעונה על שלוש שאלות: מה נכנס, מה דורש אותי, ומי נשכח |

מתחת לזה יושבת הנחת היסוד הארכיטקטונית: כל אירוע בעסק יוצר או **התחייבות**
(מישהו חייב משהו) או **ראיה** (מסמך שמוכיח אותה). מכיוון ששניהם על אותו ציר זמן,
הריטיינרים והגבייה מפסיקים לדלוף — אבל זו התוצאה, לא ההבטחה.

## ארכיטקטורה

Bossi אינה מוצר עם פיצ'רים כבויים — היא **קרנל דק ועשרה מודולים שמתחברים**.
כל לקוח מקבל הרכבה משלו, ואותו קוד משרת עסק שירותים ועסק B2B כאחד.

```bash
pnpm install
pnpm dev                # דף הנחיתה והאפליקציה
pnpm check              # typecheck + 37 בדיקות + אימות המרשם
pnpm modules services   # מה מקבל דייר עם החבילה הזו
```

הגדרת משתני סביבה: העתיקו את [`.env.example`](.env.example) ל-`.env.local`.
הפירוט המלא ב-[docs/09](docs/09-environment.md).
