# Bossi

מערכת הפעלה לעסק — לניהול הלקוחות, הכסף והמסמכים במקום אחד.

Bossi נבנית סביב הנחת יסוד אחת: **לכל עסק יש שני נכסים שהוא כל הזמן מאבד — התחייבויות וראיות.**
התחייבות היא כל דבר שמישהו חייב למישהו (לקוח חייב כסף, אנחנו חייבים שעות בריטיינר, מלאי חייב להגיע).
ראיה היא כל מסמך שמוכיח את ההתחייבות (חוזה, הצעת מחיר מאושרת, תעודת משלוח, חשבונית).

רוב העסקים הקטנים והבינוניים מנהלים את שניהם ב-WhatsApp, ב-Drive ובראש. Bossi מחברת אותם
לציר זמן אחד לכל לקוח, ומוסיפה שכבה שיודעת להתריע לפני שמשהו נופל.

## ארכיטקטורה

Bossi אינה מוצר עם פיצ'רים כבויים — היא **קרנל דק ועשרה מודולים שמתחברים**.
כל לקוח מקבל הרכבה משלו, ואותו קוד משרת עסק שירותים ועסק B2B כאחד.

```bash
pnpm install
pnpm dev                # דף הנחיתה והאפליקציה
pnpm check              # typecheck + 37 בדיקות + אימות המרשם
pnpm modules services   # מה מקבל דייר עם החבילה הזו
```

הגדרת משתני סביבה: העתיקו את [`.env.example`](.env.example) ל-`.env.local`.
הפירוט המלא ב-[docs/09](docs/09-environment.md).
